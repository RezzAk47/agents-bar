# Security

Agents Bar reads your AI coding agents' local transcript files, which can hold private prompts and code (see
[README](README.md#privacy) and [docs/DETAILS.md](docs/DETAILS.md#what-the-page-receives-privacy)). If you find a way it could
leak transcript content, or run anything other than its fixed `gh` commands, please email rzk.karimi@gmail.com with steps to
reproduce instead of opening a public issue. Do not include real transcripts or tokens.

This is a one-person project: expect a reply within a few days, not hours. Only the latest version on `main` is supported.
